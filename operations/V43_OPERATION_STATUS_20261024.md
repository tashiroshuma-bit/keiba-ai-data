## ローカルでの起動

1. リポジトリをチェックアウトし、`pip install -r requirements.txt` を実行する。
2. Libraryの正本 `jra_2023_2025.sqlite`（約322MB）を、リポジトリ直下の同名ファイルに置き換える。GitHubの28KB版を使わない。
3. 発走前に `python scripts/run_v43_shadow.py` を実行する。
4. `reports/20261025_v43_shadow/prediction.json` と `prediction.md` に予測と全買い目が出力される。モデルの選択SHA不一致、出走馬欠落、出走前締切超過は停止する。
