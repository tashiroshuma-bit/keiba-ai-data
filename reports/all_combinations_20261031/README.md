## 表示ルール

- 単勝：全頭。馬連・ワイド：全nC2通り。3連複：全nC3通り。
- 個別確率降順。丸め前の数値で順位決定。同確率は馬番・馬名キー順。
- 各券種の上位10点を先に表示し、残りも省略せず詳細に掲載。
- 馬連・3連複の累積は同一券種内の排他的事象の和。ワイドの累積は上位3頭分布から少なくとも1点が的中する確率を求め、重複を除外。
- 勝率・的中推定確率と期待値は分離。組合せオッズ未取得ならEVと配分は未算出。
- 保存時点で馬番未確認なら馬名表示。既存の発走前固定予測は上書きしない。終了レースへの事後計算は新規の発走前実績に数えない。
