# GPT内部馬IDの全出走行連携（研究用）

JRA公式馬IDを捏造せず、馬名のNFKC正規化＋レース年−馬齢から求める推定生年をハッシュ化してGPT内部馬IDを付与。正本SQLite version10（SHA256 `5a7dcd864286ccb60a43dd644a0fbe050ea25425e7e39effa7fa70fdc3128ebc`）は変更せず、独立SQLiteサイドカーに保存。

| 指標 | 実測 |
|---|---:|
| 元出走行 | 181,345 |
| 内部ID割当済み出走行 | **181,345（100%）** |
| 内部馬IDの種類 | 25,413 |
| 既存公式IDあり | 104,028行 |
| 公式ID未連携 | 77,317行 |
| レース日欠損でrace_id年を使用 | 25行 |
| 同一内部IDに異なる公式IDが付く衝突 | 0組 |
| 内部IDを介して既存公式ID行とつながる未連携行 | 16行 |
| JOIN検査 | 181,345/181,345行成功 |
| 単体テスト | 9件成功 |

**重要な制約:** GPT内部IDは馬名＋推定生年による*同一馬候補*であり、JRA公式ID・公式同一性の証明ではない。現時点で未連携77,317行に新しい公式IDが取得されたわけではない。公式IDが既存行にある場合のみ別カラムに保持。原本が確認できない同名同世代馬は誤結合の可能性がある。結果PDFから得た馬齢・馬名は発走前観測を証明しないため、当該内部IDと履歴は回顧研究用であり本番予測の使用には時刻証拠と検証が必要。

成果物: `gpt_horse_identity_v1_20261022.zip`（独立SQLite 50MB、生成コード、JOIN検証コード、9件テスト、結果JSON、SHA256 manifest。圧縮12.4MB）。元の322MB正本DBはZIPに含めない。

**次工程:** 時系列学習器で公式IDのみの履歴と内部IDベースの履歴を同一通常レースで比較。馬名＋生年キーの衝突監視、未来情報・結果漏洩検査を通した場合にのみ予測特徴へ適用。精度向上や80%達成は未検証。
