# v40 発走前データ→予測凍結→事後評価のプロトタイプ

## 成果

SQLiteベースのCLI `pipeline.py` を実装。`init` / `ingest` / `freeze` / `settle` / `coverage`。発走前情報の取得時刻と特徴量利用可能時刻、結果専用特徴量禁止、重複/時間逆転/後出し拒否、原子トランザクション、予測1点のSHA256凍結、発走後に単勝・馬連・3連複の的中を判定。17件テスト合格。元のJRA結果DBはread-only。

**注意：本番完成ではない。** 実JRA発走前原本の自動取得、取得元バイトのハッシュ照合、サーバ時刻証明、出走取消・全馬網羅、公式馬ID原本照合、将来レースでの検証が未完了。ソースURL/ハッシュ/現在時刻は入力者申告であり、偽装耐性を保証しない。公式ID確認フラグが入力されても`unverified_claim`として保存し、公式検証済みには昇格させない。実レースの新規評価0件、公式ID新規確定0件。
