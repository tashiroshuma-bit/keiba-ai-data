# JRA上位3着同時分布モデル（診断版、2026-10-07）

このモデルは、2025-10-04〜2026-09-27の保存済みJRA非重賞3,201レースと重賞129レース（計46,206頭分）から、1〜3着の順序付き確率を推定する。Google Colab 不要。3,331レースの元データのうち、同着で上位3着が一意に定まらない重賞1レースを除外した。出走頭数5頭未満、取消・返還・降着・同着は当初サポートしない。

追加で保存済みの2023〜2025年重賞アーカイブ388レースを確認した。上位3着が一意に定まる384レース（2023〜24年256、2025年128）に2026年重賞95レースを接続した**重賞専用の比較モデル**も同梱した。重賞専用モデルは非重賞の過去走を参照できないため、両者を混ぜて校正済み確率と扱わない。

## 検証条件

- 学習: 2025-10〜2026-03（1,637レース）。馬名＋生年の暫定キーで、過去の着順・同競馬場・近い距離・近3走・間隔など、各発走前までに確認できる特徴量を作る。騎手IDは約94%欠損のため使用しない。馬名一致の誤連結の可能性がある。
- 確率温度の調整: 2026-04〜06（833レース）。1〜3着の順序付き対数損失を最小化する。
- 時系列診断: 2026-07〜09（860レース）。この期間の結果は以前から検討しているため**完全な未観測の独立検証ではない**。ここで出た値を実勝率の保証に使わない。
- 直近860レースの順序付き上位3着対数損失: 6.787、一様確率7.384。モデル上位1頭の勝利率20.2%（174/860）、3着以内48.7%（419/860）。
- 直近860レースの候補ワイド（スコア上位2頭）: 事前確率平均21.8%、実測18.8%（162/860）。候補三連複（上位3頭）: 5.13%に対し実測5.12%（44/860）。
- 重賞だけ28レース: 上位1頭勝利3/28（10.7%）。ワイドの確率平均17.5%に対し実測3/28（10.7%）。重賞への適用と購入判断にはまだ不足。
- 2歳戦だけ216レース: 順序付き対数損失6.392、一様確率6.790。ただし2歳の**重賞は4レース**しかなく、スコア1位馬はこの4戦で1着も3着以内もない。次のサウジアラビアRCでの勝率の数字を購入根拠にできない。

重賞専用モデルは2023〜24年に学習、2025年に温度を調整し、既に結果を見ていた2026年に診断した。2026年7〜9月の重賞28レースで、順序付き損失7.271（一様7.604）、1位馬勝利5/28（17.9%）、上位2頭ワイド5/28（17.9%）。ワイド確率平均13.2%は28例の実測17.9%より低い。混合モデルよりこの期間の数値は改善したが、選択時点で同期間を見ているため独立した改善実証ではない。

上位3着の順序付き分布は、各馬の発走前特徴から得た強さを Plackett–Luce 式で1着、2着、3着へ条件付きに割り当てる。全 `n(n-1)(n-2)` 通りの確率が1になる。馬ごとの単勝スコアを単純に掛けた値ではないが、同型馬が先行争いする相関や騎手との適合は十分に表現していない。

## 実行

```bash
python3 -m unittest -v test_joint_top3_model.py test_ticket_math.py
python3 joint_top3_model.py --source source_packages/jra_graded_identity_jockey_validation_2026.zip --output joint_top3_outputs
python3 joint_top3_model.py --entries official_entries.csv --model joint_top3_outputs/joint_top3_model.json --out joint_top3_outputs/locked_20261010.json
python3 graded_joint_model.py --output joint_top3_outputs
python3 graded_joint_model.py --entries official_entries.csv --model joint_top3_outputs/graded_only_model.json --out joint_top3_outputs/graded_locked_20261010.json
```

必要なCSV列: `race_id,date,course,surface,distance,frame,number,horse,sex,age,source_url`。公式出馬表に掲載された**全頭**を記録し、取消があれば正式な出走一覧を確定した後で再作成する。頭数・枠・馬番の未確定情報を埋めない。発走前にCSVと予測JSONを保存し、予測時刻・モデル版・同時刻のオッズを別途固定する。保存データの終点2026-09-27以降の過去走はまだ反映していないため、最新走がある馬については更新または利用保留とする。

出力JSONの `validation_status` は `historical_diagnostic_only`。既存の `ticket_math.py forecast` は**独立に確率校正を検証した分布だけ**を受け付けるため、このJSONを使った馬券の期待値・推奨額は計算できない。フラグを書き換えて通さない。発走前オッズ・確定払戻を揃え、未観測の将来重賞でワイド／三連複の頻度校正、当たり率、購入率、レース投票額回収率、実現回収率を先に確認する。重賞で確率の過大評価が解消するまでは数値を購入根拠にしない。

データ出典: パッケージに含めた既存のJRA成績CSV、過去走履歴、予測プログラムと診断JSON。元データは2026-10-07時点で既に収集されていたもの。新しい外部データの取得や、2026-10-10の出走馬への予測はここでは実施していない。
