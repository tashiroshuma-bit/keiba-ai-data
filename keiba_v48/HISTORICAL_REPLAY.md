# 公式ID連携・時刻台帳・研究用実測検証

2026-10-19実施。対象の原データは2023～2025年のJRA全成績PDF864件、10,368レース、142,737掲載馬行。

## IDと根拠

`official_linkage.py`はJRAが実際に掲載している結果ページのリンクをたどり、馬の競走馬情報URLと騎手プロフィールのコードから`jra:`名前空間のIDを取得する。レースID・馬番・馬名・生年をPDFと照合する。名前から公式番号を生成しない。

- `official_identity_evidence`：照合したソース行、URL、SHA256、取得時刻、結果ページの原項目。
- `annual_identity_links`：各掲載馬行の連携方法と根拠行への参照。直接のソース行照合と、馬名＋生年の一致／一意な騎手名による展開を区別する。
- 同名同年の異なるIDや騎手名のID競合は一括結合しない。PDFの欠落文字を曖昧一致で修復しない。減量記号だけを名前から取り除く。
- 401・403・429を受けた取得は停止する。キャッシュ再利用時もチェックサムを照合する。

今回のID根拠は6,382頭・160騎手。馬ID64,385行、騎手ID134,601行、両方60,768行を連携した。延べ掲載行数であり、公式IDの全頭・全騎手網羅ではない。文字欠損、一時免許・引退等でリンクがない騎手、未取得の馬が残る。

## 時刻の意味

`annual_time_evidence`に予定発走、結果ページの表示発走時刻、実発走、結果公表、初回取得を分けて記録する。PDFの発走時刻は[公式解説](https://www.jra.go.jp/datafile/seiseki/report/mikata4.html)で出馬表記載の定刻とされている。結果ページ表示時刻には差があるため、予定時刻を上書きせず別フィールドに保存する。実発走と確定結果公表の厳密な時刻は未確認のままNULL。

全10,368レースの時刻台帳を作成し、572レースで結果ページの表示発走時刻を併記した。PDFとの差分は40レース。再実行時も、既存の実発走・公表・初回観測時刻を上書きしない。

JRAの[年度別全成績案内](https://www.jra.go.jp/datafile/seiseki/report/)は翌日掲載を案内している。ただし、現在の掲載方針を過去の特定PDFの実測公表時刻とは扱わない。

2025-05-31東京9Rの結果HTML欠落については、[JRAの取りやめ・発走時刻変更発表](https://www.jra.go.jp/news/202505/053104.html)を確認した。欠落レースの結果やIDは生成しない。

## 再実行

```bash
python keiba_v48/official_linkage.py --db jra_2023_2025.sqlite --cache official_html_cache --seed-file keiba_v48/official_linkage_seeds.json --max-pages 700 --report linkage_audit.json
python keiba_v48/official_linkage.py --db jra_2023_2025.sqlite --cache official_html_cache --refresh-links-only --report linkage_audit.json
python keiba_v48/annual_export.py --db jra_2023_2025.sqlite --output annual_output
python keiba_v48/historical_replay.py --db jra_2023_2025.sqlite --output replay_output --lags 2 7
```

DBを使用する処理は直列に実行する。`--max-pages`はその実行でたどる上限で、全年度の網羅保証ではない。種URLは2023～2025年それぞれの1月、5～6月、10月の公式結果から選び、ページ内にある開催日の全レースリンクへ展開した。全10場・全月を代表する無作為標本ではない。

## 検証の条件と結果

結果がレース日の2日後／7日後の日本時間0時に利用できたと仮定する研究用リプレイ。これは公表時刻の観測値ではなく、原データの`result_available_at`は空欄を維持する。`availability_basis=assumed_...`を持つ履歴は通常の履歴統合に拒否され、研究用モデルも本番用ロードで拒否される。

完全な馬・騎手ID、構造照合通過、全頭の一意な着順がそろうレースだけを対象に、2023年109レースで学習、2024年98レースで温度校正、2025年86レースで評価した。テスト日は8日で、10月に55レースが偏る。2025年は既に探索に使用した期間で、未知のホールドアウトではない。

発走前の観測時刻を確認できない当日馬場・斤量・馬体重・オッズは現在値の特徴に使用しない。過去走の馬場と結果は仮定した利用可能時刻以降だけ参照する。掲載順に並べると勝馬が先頭になるため、入力と同率時の選択は馬番で固定した。

| 項目 | 2日後利用 | 7日後利用 |
|---|---:|---:|
| 評価レース | 86 | 86 |
| 単勝1位の的中率 | 22.09%（19/86） | 22.09%（19/86） |
| 勝率の対数損失（低いほど良い） | 2.33848 | 2.34107 |
| 全頭等確率の対数損失 | 2.61538 | 2.61538 |
| 固定単勝100円の購入総額 | 8,600円 | 8,600円 |
| 払戻総額 | 6,830円 | 6,830円 |
| 回収率 | 79.42% | 79.42% |
| 損益 | -1,770円 | -1,770円 |
| 最大ドローダウン（元手10万円） | 2.37% | 2.37% |

2日後利用時の、過去の3着内率を縮約した単純基準の対数損失は2.46336。今回の標本内では勝率の誤差が小さくなったが、利益は確認できない。開催日単位のブートストラップによる固定単勝回収率の95%範囲は42.0～121.4%で、8開催日という少数標本の制約が強い。100%超の収益性を示す結果ではない。

回収率は全対象で最大確率の馬に100円ずつ買う固定ルールの後方検証。公式単勝払戻は精算だけに使用し、勝率や選択の入力に使用しない。発走前オッズによる期待値選別、ワイド・3連複、1レース5,000円配分の運用成績は別途検証が必要。

## 受け入れ状況

- 機能・回帰テスト84件、compileall、差分検査を実施。
- ID競合、原文とURLの開催不一致、同率選択の着順依存、仮定時刻の本番混入、再解析後の古いID再利用をテスト。
- DB整合性`ok`、外部キー違反0、要確認レースの確定着順漏出0。HTMLとPDFで照合可能だった着順の不一致0。
- JSONに入力DB、モデル、予測行、関連ソースコードのSHA256を保持。
- 厳密な過去公表時刻が確認できた行は0。研究用モデルの本番採用は保留。

残る主な作業は、未連携馬・文字欠損騎手の追加ソース照合、全場全月への対象拡張、時刻付き出馬表・オッズの蓄積、予測を事前固定した前向き検証。コードの機能合格、研究用の実データ検証、実運用での収益性を区別して追跡する。
