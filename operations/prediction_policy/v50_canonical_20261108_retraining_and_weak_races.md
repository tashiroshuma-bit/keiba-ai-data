# v50 継続研究｜正本DB再学習と苦手レース診断（2026-11-08）

## 判定
- **正本DB v10の実データ再学習と独立年度検証は完了**。ただし、これは新しい馬・騎手研究モデルで、正式稼働v50をそのまま再構築した比較ではない。
- 正式v50のバージョン、基礎モデル、騎手残差、勝率係数は**維持**。優越性未証明の研究係数を勝手に本番へ反映していない。
- 予測前に計算できる「苦手レース警戒フラグ」を正式予測の **research/shadow 表示**へ接続。通常・大波乱のどちらでも全頭の確率・予測順位は変更しない。

## データの真正性と時間分割
- 正本 `jra_2023_2025.sqlite` 322,121,728 bytes。SHA256 `5a7dcd864286ccb60a43dd644a0fbe050ea25425e7e39effa7fa70fdc3128ebc` は `PROJECT_STATE.json` と一致。
- PDF年次データから、平地・勝ち馬/出走頭数/馬番に整合したレースを抽出：2023年2,910R、2024年2,858R、2025年2,890R、2026年2,384R、合計**11,042R**。
- 2026年の保存内容は**10月18日まで**。11月8日そのものはDB再学習にも係数選択にも含めていない。
- 2023年学習 → 2024年で正則化・特徴量選択 → 2023–24年で再学習 → 2025年に未知年度で評価・確率と難易度を校正 → 2026年を最終未学習評価。
- 各馬の過去走歴を、レース日から**2暦日以上前に終了したレースのみ**で作成。同日レース・対象レースの着順/最終オッズ/対象レース走破タイム/当日馬場結果は学習特徴量として使わない。
- 馬IDの未連携は別馬と勝手に結合しない。実測で使用した確認済み馬IDの行は86,402、騎手ID146,961、過去の馬別走歴を参照できた行76,970。
- PDF結果から静的情報を復元しているため、個々の特徴量の**発走前の公開時刻までは証明していない**。結果公開時点を発走後2日と仮定する研究用再生であり、厳密な本番のpoint-in-time証明ではない。

## 再学習モデルの苦手なレース：2年度で再現した事前条件

|発走前の区分|2025年 1着指名|2026年 1着指名|解釈|
|---|---:|---:|---|
|本命と2番手の確率差2pp未満|107/697（15.4%）|93/667（13.9%）|接戦の識別が弱い|
|本命と2番手の確率差6pp以上|352/1,433（24.6%）|253/1,055（24.0%）|比較的得意|
|予測分布の正規化エントロピー0.95以上|136/908（15.0%）|189/1,126（16.8%）|全頭の能力が拮抗|
|本命の推定勝率15%未満|93/676（13.8%）|106/760（13.9%）|本命選択の信頼性が低い|
|出走14頭以上|357/1,824（19.6%）|258/1,457（17.7%）|頭数固有の難しさを考慮|
|9頭以下|81/322（25.2%）|62/260（23.8%）|頭数効果が混ざるため直接の優劣断定不可|

**競馬場や馬ID欠損だけを理由に加点・減点する明確な証拠はない。** 多頭数は元々当選確率が下がるため、頭数別の粗い的中率だけを因果要因と断定しない。

**事後にだけわかる分類：** 勝ち馬が最終4番人気以下のとき、モデルの1着指名は2025年42/951（4.4%）、2026年41/824（5.0%）。大きな弱点だが、最終人気は予測前に使えないため、本命と市場の直前乖離や近走能力に分解する必要がある。

## 誤った高確率と校正
- 本命推定勝率30%以上のレースでは、2025年の実測勝率26.8%に対して予測本命p1平均40.1%、2026年は実測26.0%に対して予測平均39.5%。**高信頼帯の過信**が継続。
- 2025年だけで温度係数を推定した結果は **1.0398**。2026年未学習2,384RでLog Loss 2.413078→2.412907、Brier 0.894059→0.893391。**順位や的中数は472のまま**。改善は小さい。

## 「勝ち馬を予測上位3頭から外す」苦手レースの事前識別
- 2025年の正本DB研究予測を使い、事前p1/top3質量、上位差、エントロピー、頭数、馬履歴未観測の割合、芝ダートで実際の上位3頭漏れを学習。
- 2026年2,384Rでは勝馬が予測上位3頭の外：**1,298/2,384R（54.4%）**。
- 上位3頭の推定確率からそのまま失敗率を推定した場合：Brier 0.2476、AUC 0.5690。
- 2025年で学習した失敗リスク分類器：2026年 Brier **0.2428**、AUC **0.5804**。
- **2025年で固定した境界値**による2026年評価：高リスク判定551R中348R（**63.2%**）が勝ち馬をtop3に捕捉できず、低リスク判定419R中178R（**42.5%**）が失敗。
- AUC0.5804は小幅な識別力であり、確実な「買わないレース」判定や大波乱検知と混同しない。

## 11月8日 v50 A–D研究Cとの別系統照合
- JRA公式11月8日平地34R、前日研究Cの1着指名 **10/34**、勝ち馬上位3捕捉 **16/34**。公式結果対照：`operations/results/2026-11-08/v50_abcd_settlement.md`。
- 14頭以上23Rで勝ち馬上位3捕捉8R（34.8%）、10〜13頭8Rでは7R（87.5%）。1日の観測であり、この比率を原因として固定補正しない。
- 実際に4番人気以下が勝った13RはC本命0/13。これは**結果判明後の分類**であり、レース前の特徴量に使っていない。

## 次回の研究運用・採用制限
1. 標準v50を維持。新たな再学習モデルは`research/shadow`のみで本命順や券種を変更しない。
2. `scripts/v50_difficulty_flags.py` と `scripts/standard_v50_forecast.py` を接続済み。予測時のp1/頭数/上位差/エントロピーで非校正の注意フラグを付ける。通常レースでは本命も確率も変えない。
3. 先に検証した東京11R級の超大波乱フラグは**無効**。2025年351Rで1例、広義13例、学習で選んだルールは後続125Rで再現せず。
4. 正式採用ゲート：既存v50と**同じレース・発走前特徴量・同じ馬番**で確率を保存、後日1着/Top3/3頭一致/Log Loss/Brier、校正、頭数別比較を時系列ホールドアウトで評価。未改善なら本番へ昇格させない。

## 再現手順（canonical DBファイルをローカルに置くこと）
```bash
pip install numpy scipy
export KEIBA_CANONICAL_DB=/absolute/path/jra_2023_2025.sqlite
export KEIBA_RETRAIN_OUTPUT_DIR=/absolute/path/output
python -m scripts.retrain_v50_canonical_db_shadow
python -m scripts.calibrate_v50_canonical_db_race_risk
```
正本DBのSHA256が `PROJECT_STATE.database.sha256` と異なる場合は**再学習を停止**する。GitHub Actionsに私有322MBのDBを暗黙に取り込む仕組みはないため、DB不要のスモークテストのみCIで検証する。
