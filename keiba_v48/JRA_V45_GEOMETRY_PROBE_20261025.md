5. `requirements.txt` に `PyMuPDF>=1.24,<2` を追加。PyMuPDFはAGPL系ライセンスのため、商用非公開配布等に利用する場合はライセンス確認が必要。

## 実行例（実原本が許可された経路で手元にある場合のみ）
```bash
python keiba_v48/jra_v45_program_layout_probe.py \
  --pdf /path/to/official-venue-program.pdf \
  --source-url https://www.jra.go.jp/keiba/rpdf/pdf/20261024-04tokyo08.pdf \
  --observed-at 2026-10-25T09:14:00+09:00 \
  --out /path/to/local-probe.json
```
**注意：** 上記時刻は使用例であり、実際にPDFバイトを取得した観測時刻ではない。正しい原本取得時刻を記録すること。CLIは入力時刻・URLの真正性を検証せず、出力は必ず `CANDIDATES_ONLY_UNVERIFIED`、`production_freeze_allowed=false`、`result_settlement_allowed=false`。候補が揃っても別公式出馬表・取消情報・時刻根拠との照合なしに本番化しない。
