# 相手との相対評価を加えた順位モデルの検証（2026-10-25）

順位を変える相対評価モデルを実装・学習し、両遅延条件で各6,036レースを再検証した。確率誤差は改善したが、1着指名は両年・両条件で低下したため、この候補の係数を次回標準へ採用しない。目標の1着80%・順序50%・順不同60%は未達。

## 今回反映した修正

- 学習候補：同じレースの相手と比べた能力・近走・コース・距離・騎手・末脚・着差・相手水準・騎手との相性・過去勝率など12項目を追加。相対標準値と同率を考慮した順位比を使い、非線形の条件付き順位木で学習。
- 入力経路：次回の研究予測は正本DBの観測済み走歴から特徴量を再計算する入口を用意。通算成績だけを使って大半を学習時平均で埋めた10/25の代用入力とは混用しない。
- 根拠表示：全出走馬を残し、実際に参照できた走歴が0件・3件未満の馬の数を表示。情報不足を解消したと偽らず、架空の走歴・ID・発走前観測を補わない。
- 保存：モデル・選択・補正のSHA256を固定したプロフィールから発走前予測を生成し、新しい出力名と台帳へ保存。稼働モデルの昇格・実馬券生成は行わない。

10/25の入力は `scripts/forecast_20261025_rank_shadow.py` の `predict` で確認できる通算成績の代用分布であり、今回の数千レースの完全走歴による比較とは母集団・入力条件が異なる。週末のB=20.0%から下表の22%へ改善したとは主張しない。

## 学習・選択方法

正本version 10（322,121,728バイト、SHA256 5a7dcd864286ccb60a43dd644a0fbe050ea25425e7e39effa7fa70fdc3128ebc）を読み取り専用で使用。取得後のハッシュ・SQLite quick_check・共通台帳検査が一致。DB原本の変更はない。

2023年3,358レースで学習、2024年前半1,745レースで温度補正、後半は2日遅延1,615件・7日遅延1,579件で選択。2025年3,329件・2026年2,707件は既に見た回顧評価であり、独立の将来検証ではない。過去データの公開は2日/7日遅延の仮定を継承し、実際の過去公開時刻を復元したものではない。

候補はwin/shared/stagewiseの3系統、各120本の深さ2の木、従来モデルへの混合率10/25/50/100%、順不同3頭の選び方2通りを事前プロトコルに固定。2024年選択で3つの完全一致件数を一つも落とさない候補から選択した。重みと選択を保存してから2025/2026を計算したが、2024年の選択期間も再利用しており探索上の過学習リスクは残る。

## 選択と採否

2024年だけの選択結果は2日条件が `relative_win_d2_w0.1_exact_set`、7日条件が `relative_win_d2_w0.5_exact_set`。2日条件は2024年の1着374→375、順序22→22、順不同80→81。7日条件は362→365、20→20、77→87。2025/2026を見てこの重みを別の値へ変更していない。

**次回の標準への係数採用は見送り。** 従来の2024年選択済みモデルと補正を使用する。今回の候補は明示指定による研究比較に限定し、正式forward件数は0のまま。相対特徴量と順不同の決定方法が同時に変わる候補があるため、組一致の差すべてを特徴量追加の効果と断定しない。

## 次回用の実行入口

`scripts/forecast_rank_profile.py` と `operations/prediction_policy/observed_history_rank.json` を追加した。出走馬JSONは全頭・公式ID・出典URL・原本hash・実観測時刻を含むものを使い、`feature_generation_mode=observed_history` を指定する。未来の出馬表や予測を今回生成したわけではない。

```bash
python scripts/forecast_rank_profile.py --db CANONICAL_DB --runners PREOFF_CARD_JSON --profile operations/prediction_policy/observed_history_rank.json --lag 7 --ledger LEDGER_PATH --output NEW_PREDICTION_JSON
```

全頭の実データが揃わない場合は、平均値の代用入力を正式な予測として出さず、不足を表示する。走歴0件の馬の順位は弱い根拠であることを出力に残す。外部AIとの4モデル比較は同じ内部予測の別混合として扱い、独立4モデルの一致とは表現しない。
