# 上位3頭への勝ち馬捕捉: binary relevance ranking 追加検証 (2026-10-22)

## 条件

- 正本 SQLite version 10、SHA256 `5a7dcd864286ccb60a43dd644a0fbe050ea25425e7e39effa7fa70fdc3128ebc`。
- 目的は各レースで1着馬がモデルの上位3頭に含まれる率。結果オッズ・払戻は使用しない。
- 特徴量は7日隔離した過去成績から計算。現在レースの年齢・枠・距離・馬場等、発走前観測時刻が未確認の特徴を除外。ただしIDの当時観測時刻は未証明。
- 学習: 2023→2024年後半の選択、2023-24→2025年回顧、2023-25→2026年回顧。2025/26はすでに繰り返し閲覧済みで未見テストではない。
- CatBoost二経路モデルと、勝者だけを relevance=1 としたLightGBM LambdaRank / rank_xendcgを比較。2024年後半の同一1,387レースだけで候補を選択。2026年は2,411レースの限定コホートであり、公式完全一致評価2,707レースと同一母集団ではない。

## 実測

| モデル | 2024年後半 (選択) | 2025年回顧 | 2026年回顧 |
|---|---:|---:|---:|
| 年次再学習 CatBoost二経路 (基準) | 693/1387 = 49.96% | 1478/2925 = **50.53%** | 1161/2411 = **48.15%** |
| 2024年で選択した rank_xendcg と CatBoost の混合 | 706/1387 = **50.90%** | 1447/2925 = 49.47% | 1150/2411 = 47.70% |
| LambdaRank と CatBoost の混合 (未選択) | 690/1387 = 49.75% | 1467/2925 = 50.15% | 1163/2411 = 48.24% |

2024年で選んだ候補は2025/26で基準より悪化。**新方式を不採用**とし、従来の本番モデルも変更しない。2026年基準の二項Wilson 95%区間は46.16–50.15%、目標80%には届かない。

## 2026年基準モデルの失敗集中

- 1着馬の公式馬IDが連携済み: 332/649 = 51.16%。未連携: 829/1762 = 47.05%。未連携勝者の割合73.08%。
- 3–9頭: 165/264 = 62.50%。10–13頭: 352/686 = 51.31%。14頭以上: 644/1461 = **44.08%**。
- 全頭を予測する本来の条件で、少頭数や連携済みレースだけに絞って80%達成を主張しない。

## 次の修復と昇格条件

1. 公式証拠に基づき未連携馬IDと騎手IDを解決し、発走前の実観測時刻と出走馬全頭スナップショットを保存する。
2. 公式適格コホートと研究コホートの欠落レースを照合し、選択・評価の母集団を一致させる。
3. 事前固定した未見レースの予測を残し、未来の成績で改善を判定する。既知2025/26への後知恵選択をしない。
4. 重みと全頭予測の保存・別プロセス再生・テストを通したものだけ昇格候補にする。
