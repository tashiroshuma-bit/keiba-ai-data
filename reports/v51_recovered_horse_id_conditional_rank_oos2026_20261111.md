**2026年11月11日。研究用v51のみ。標準v50の係数・予測処理は変更しない。**

- 学習：2023–2024年検証済み **5,865レース・80,547頭**。2025年は温度校正専用、2026年はモデル重み・温度を固定した独立評価 **2,411レース**。学習済みパラメータは研究モデル `operations/prediction_policy/v51_rank_recovered_ids_cal2025_research.json`、比較条件 `v51_rank_old_ids_masked_control.json`。
- 2025年の勝率校正は軸別3温度と、初期の正規化エントロピー0.94・最有力馬0.25を境界にした4群。小標本は全体温度へ戻し、2026年の実着順・的中率から一切設定を選ばない。

### 2着・3着条件付きモデルの独立検証（2026年2,411R）

2025年で温度校正したモデルを2026年で固定評価した実測値（小さいほど良い）。正式v50との比較ではなく、旧馬ID欠測を再現した条件付き順位モデルとの同条件比較：

| 2026年の評価 | 旧馬ID欠測を再現 | v12復元ID | 改善方向 |
|---|---:|---:|---|
| 実2着馬の周辺確率 Log Loss | 2.4664 | **2.3529** | 改善 |
| 実3着馬の周辺確率 Log Loss | 2.5097 | **2.4433** | 改善 |
| 実2着馬の周辺確率 Brier | 0.90452 | **0.88673** | 改善 |
| 実3着馬の周辺確率 Brier | 0.91063 | **0.90243** | 改善 |
| P(2着｜実1着) 条件付き Log Loss | 2.3542 | **2.2177** | 改善 |
| P(3着｜実1・2着) 条件付き Log Loss | 2.2874 | **2.1871** | 改善 |

校正をかけたこと自体による2着・3着の改善は**一様ではない**。例えばv12モデルの2026年2着周辺Log Lossは校正前2.35266、校正後2.35294と微悪化。この点は独立の順位別温度再評価が必要であり、現時点のv51完成扱いやv50置換はしない。

## 本番v50と**同一レース・同一予測時点**での直接比較

新しいオプトイン引数：
```bash
python -m scripts.standard_v50_forecast --forecast /data/real_source_A.json \
  --database /data/verified_v12.sqlite --output /data/v50_with_shadow.json \
  --v51-recovered-rank-features /data/v51_full_field_features_same_source_A.json
```
`v51_v50_same_asof_shadow.py` は現行標準v50の本物の `forecast_sha256`、`forecast_asof`、全レース・全馬番・馬名・公式ID原本ハッシュ、特徴量生成／観測時刻、出走時刻、過去結果の日付カットオフ、v12正本SHAを照合し、不整合時は停止。最後の出力は `v51_recovered_rank_shadow` に研究用として追加するのみで、既存の `races[*].v50` を変更しない。

**ただしこのPRで実際のv50対v51実測勝負を行ったとは主張しない。** 2025–26の全5,336レースについて、当時凍結済みの正式v50全馬確率・同時刻のモデルA原本・v51特徴量を一対一で整列する真の過去アーカイブが揃っていない。コードと合成CIの成功は、2026実データでのv51対v50優位性の証明ではない。実レースの同一時点スナップショット取得後、上記オプトイン生成・公式全頭着順検証を実行し `postrace()` に渡す。

## 本番昇格判定
- **v50正式版を維持、v51非昇格**。将来のレースの予測時点を揃えた完全対戦、独立校正の再評価、Brier/Log Lossだけでなく順位一致と確率帯過信、混戦レース別ドリフト、馬場・騎手差などが昇格条件。
- 上位3頭全組の最高確率を出す条件付き順位モデルは、単勝勝率順に3頭を並べるv50代理比較より厳密な順序構造を持つが、直接確率の評価が必要。
